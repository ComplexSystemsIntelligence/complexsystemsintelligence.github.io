About the group

From data to systems that learn

We turn data from interconnected processes, organisations and regions into transparent models, monitoring tools and decision support.

This site is the open-education and open-science home of the Complex Systems Monitoring Research Group (AbonyiLab) at the University of Pannonia, Veszprém, Hungary. Alongside research, the group trains the engineers and data scientists who build such systems – and publishes the teaching materials openly, so that anyone can learn from them.

Research code and earlier toolboxes are available on github.com/abonyilab; news, publications and projects on abonyilab.com.

Software and data

Tools and datasets to build on

Research code

  • NOCAD – network-based observability and controllability analysis of dynamical systems
  • HAT-VIS – hypergraph visualisation toolbox
  • Operator 4.0 Laboratory – data and scripts from laboratory demonstrations
  • ObServML – deployable Python application for compact, modular systems monitoring (SoftwareX, 2026)

Toolboxes

  • Fuzzy Clustering and Data Analysis Toolbox – MATLAB; a Python successor is under development
  • GP-OLS – genetic programming for nonlinear input–output models
  • EASY-IEC – interactive evolutionary computing
  • MATLAB Central author page

Open datasets

  • Erasmus mobility network – multilayer, spatial network of European higher-education mobility (Scientific Data, 2020)
  • World news and SDG monitoring – news-based SDG data with BigQuery scripts (Data in Brief, 2021)
  • Regional Industry 4.0 readiness index – 101 indicators for NUTS 2 regions (2020)
