# complexsystemsintelligence.github.io

Source of the landing page **https://complexsystemsintelligence.github.io/** – the portal of the
open textbooks, research software and data of the
[HUN-REN–PE Complex Systems Monitoring Research Group](https://www.abonyilab.com) (AbonyiLab),
University of Pannonia, Veszprém, Hungary.

- `index.html` – the page (self-contained HTML, CSS and a small canvas script)
- `assets/` – self-hosted fonts (Raleway, IBM Plex; SIL OFL 1.1), University of Pannonia logos, book covers, social image

The site is served by GitHub Pages from the `main` branch. The textbooks themselves live in their own
repositories and are published under this domain:
[adatbanyaszat](https://complexsystemsintelligence.github.io/adatbanyaszat/),
[biztonsagkritikus-rendszerek](https://complexsystemsintelligence.github.io/biztonsagkritikus-rendszerek/),
[rendszermernokseg](https://github.com/ComplexSystemsIntelligence/rendszermernokseg).

The name, crest and logo of the University of Pannonia are elements of the university's visual
identity and are not covered by any open licence.
